# まなだMOViE / aisa ポートフォリオ・プロトタイプ

動画・SNS制作ブランド「まなだMOViE」と、AI・業務自動化ブランド「aisa」の2ブランド構成を確認するためのデザインプロトタイプです。

## 起動方法

Node.js 22.13以上を利用してください。

```bash
npm install
npm run dev
```

ブラウザで `http://localhost:3000` を開きます。本番相当のビルド確認は `npm run build` で実行できます。

## ページ

- `/`：2ブランド共通入口
- `/movie`：まなだMOViE ポートフォリオ
- `/aisa`：aisa ポートフォリオ

## 主要ファイル構成

```text
app/
├── components/
│   ├── BrandHeader.tsx    # 共通レスポンシブナビゲーション
│   └── SectionHeading.tsx # 共通セクション見出し
├── data/
│   ├── movie.ts           # 作品・強みデータ
│   └── aisa.ts            # 事例・課題データ
├── movie/page.tsx         # まなだMOViE
├── aisa/page.tsx          # aisa
├── globals.css            # ブランド変数・全ページのレスポンシブスタイル
├── layout.tsx
└── page.tsx               # 共通入口
```

## レスポンシブ表示確認

2026-07-17に、以下の全ページ（`/`、`/movie`、`/aisa`）を確認しました。

| 幅 | 想定 | 確認結果 |
| --- | --- | --- |
| 375px | スマートフォン | 共通入口は上下配置、カードは1列、モバイルメニューへ切替。横スクロールなし |
| 768px | タブレット | 共通入口は上下配置、ブランドページは読みやすい1列構成。横スクロールなし |
| 1024px | PC / 横長タブレット | 共通入口は左右分割、作品・事例は2列。ナビゲーション表示正常 |
| 1440px | PC | 左右50:50とホバー時55:45、広い余白、2列カード表示を確認 |

キーボードフォーカス、リンク遷移、モバイルメニュー、`prefers-reduced-motion` も確認対象に含めています。作品・事例・実績数値はすべてプロトタイプ用の仮データです。

## 今回の対象外

フォーム送信、データベース、CMS、本番SEO、アクセス解析、作品詳細ページは実装していません。「詳細を見る」ボタンはカードの見た目と操作領域を確認するためのダミーです。
